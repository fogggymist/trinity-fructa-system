# Trinity Fructa Inventory Management System

## Project Description

The Trinity Fructa Inventory Management System is a web-based application developed to manage inventory operations within Trinity Fructa Pvt. Ltd.

The system provides modules for:

* Supplier Management
* Purchase Order Management
* Raw Material Management
* Production Request Management
* Finished Goods Management
* Dispatch Management
* Accounts Management
* Reports Generation

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MySQL
* XAMPP

## Installation

1. Clone the repository.

```bash
git clone https://github.com/fogggymist/trinity-fructa-system.git
```

2. Install dependencies.

```bash
npm install
```

3. Import the provided SQL database file into MySQL.

4. Configure database settings in:

```txt
config/db.js
```

5. Start the application.

```bash
node server.js
```

6. Open the application in your browser.

```txt
http://localhost:3000/pages/dashboard.html
```
